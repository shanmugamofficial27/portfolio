# V Shanmugam · Product Designer portfolio

A one-page portfolio told as a night drive: the page starts at 8:00 PM and reaches sunrise at the bottom, with the time shown in the nav clock.

- **Work:** three case studies (Genix.ai, Billcostro, Moolago), each with its own link, e.g. `#/work/genix`
- **Skills:** a stretch of road where passing headlights light up each skill
- **Journey:** a short road from electronics engineering to product design
- **Desk:** a small 3D puzzle (unlock the laptop) built with Three.js
- **Connect:** email, LinkedIn and resume

## Run it

Open `index.html` in a browser. There is no build step. Everything lives in that one file, and the images are in `images/`.

## Adding real content

Search `index.html` for `REPLACE` to find every placeholder: project media (set `src` on a media item), resume link (`resume.pdf`), Billcostro role names and the Moolago permission-flow steps.
